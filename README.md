## 🚀 Deployment & CI/CD

- **GitHub Pages via GitHub Actions:** Configured in `.github/workflows/deploy.yml`. Automatically builds and deploys on every push to `main`.
- **GitHub Pages via `gh-pages`:** Run `npm run deploy:gh` for 1-click deployment.

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
