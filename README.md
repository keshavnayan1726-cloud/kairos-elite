## 🚀 Zero-Budget Deployment (GitHub Pages & Vercel)

This application is engineered for **₹0 / $0 permanent hosting cost** using pure static builds with infinite CDN scalability.

### Option 1: Deploy to GitHub Pages (Automated 1-Click)
1. In `package.json`, the deployment script is already wired:
   ```bash
   npm run deploy:gh
   ```
2. In your GitHub repository settings, set **Pages** source to `gh-pages` branch.  
   Your website will immediately be live at `https://<your-username>.github.io/<repo-name>/`.
3. Because `vite.config.js` sets `base: './'`, all Three.js scripts, fonts, and assets will load without any 404 path errors.

### Option 2: Deploy to Vercel (Zero Config)
1. Push your repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **Import Project**.
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**. Your custom domain can be linked for free.
